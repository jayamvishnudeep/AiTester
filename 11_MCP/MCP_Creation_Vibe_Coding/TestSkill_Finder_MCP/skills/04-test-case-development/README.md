# Test Case Development

Phase 4 of the software testing life cycle (STLC): 4 skills. Each folder holds a `SKILL.md`: a short header plus the instructions an AI assistant follows.

| Skill | What it does | From |
|---|---|---|
| [test-case-writer](test-case-writer/SKILL.md) | Expand approved test scenarios into detailed, executable test cases. | skillmasterclass |
| [test-data-generator](test-data-generator/SKILL.md) | Produce the data sets a scenario or test case needs to run. | skillmasterclass |
| [test-data-privacy-masker](test-data-privacy-masker/SKILL.md) | Plan safe test data: mask, subset or synthesise data so no real personal data reaches test environments. | added here |
| [traceability-matrix-builder](traceability-matrix-builder/SKILL.md) | Build a requirements traceability matrix (RTM). | added here |

Search them by keyword with the [Test Skill Finder MCP](../../README.md), or install one in Claude Code by copying
its folder to `~/.claude/skills/`.
