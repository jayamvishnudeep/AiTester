# Defect Management

Phase 6 of the software testing life cycle (STLC): 3 skills. Each folder holds a `SKILL.md`: a short header plus the instructions an AI assistant follows.

| Skill | What it does | From |
|---|---|---|
| [bug-reporter](bug-reporter/SKILL.md) | Turn a failure into a clean, reproducible bug report. | skillmasterclass |
| [bug-triage-assistant](bug-triage-assistant/SKILL.md) | Triage a batch of defects instead of grinding through them one by one. | skillmasterclass |
| [rca-analyzer](rca-analyzer/SKILL.md) | Run a structured root-cause analysis on a defect. | skillmasterclass |

Search them by keyword with the [Test Skill Finder MCP](../../README.md), or install one in Claude Code by copying
its folder to `~/.claude/skills/`.
