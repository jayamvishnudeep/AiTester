# Test Design

Phase 3 of the software testing life cycle (STLC): 8 skills. Each folder holds a `SKILL.md`: a short header plus the instructions an AI assistant follows.

| Skill | What it does | From |
|---|---|---|
| [accessibility-test-designer](accessibility-test-designer/SKILL.md) | Design manual and automated accessibility tests against WCAG 2.2. | added here |
| [api-test-designer](api-test-designer/SKILL.md) | Design API-level test coverage from an endpoint or contract. | skillmasterclass |
| [bdd-scenario-writer](bdd-scenario-writer/SKILL.md) | Write BDD feature files in Gherkin for Cucumber, SpecFlow, Behave or playwright-bdd. | added here |
| [boundary-value-designer](boundary-value-designer/SKILL.md) | Design test inputs with boundary value analysis, equivalence partitioning and decision tables. | added here |
| [database-test-designer](database-test-designer/SKILL.md) | Design database tests: schema, constraints, data integrity, stored logic and migrations. | added here |
| [exploratory-charter-writer](exploratory-charter-writer/SKILL.md) | Write session-based exploratory testing charters. | added here |
| [localization-test-designer](localization-test-designer/SKILL.md) | Design internationalisation (i18n) and localisation (l10n) tests. | added here |
| [test-scenario-designer](test-scenario-designer/SKILL.md) | Derive high-level test scenarios from a requirement or acceptance criteria before anyone writes detailed steps. | skillmasterclass |

Search them by keyword with the [Test Skill Finder MCP](../../README.md), or install one in Claude Code by copying
its folder to `~/.claude/skills/`.
