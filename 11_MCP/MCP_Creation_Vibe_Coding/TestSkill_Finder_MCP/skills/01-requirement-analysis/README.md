# Requirement Analysis

Phase 1 of the software testing life cycle (STLC): 3 skills. Each folder holds a `SKILL.md`: a short header plus the instructions an AI assistant follows.

| Skill | What it does | From |
|---|---|---|
| [acceptance-criteria-writer](acceptance-criteria-writer/SKILL.md) | Turn a user story into clear Given/When/Then acceptance criteria. | added here |
| [jira-requirement-analyzer](jira-requirement-analyzer/SKILL.md) | Read a JIRA ticket and judge whether it is actually ready to test. | skillmasterclass |
| [requirement-testability-reviewer](requirement-testability-reviewer/SKILL.md) | Review a requirement, user story or spec for testability before testing starts. | added here |

Search them by keyword with the [Test Skill Finder MCP](../../README.md), or install one in Claude Code by copying
its folder to `~/.claude/skills/`.
