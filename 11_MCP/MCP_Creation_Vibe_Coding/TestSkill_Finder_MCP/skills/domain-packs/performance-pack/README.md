# Performance pack

A domain pack: 6 skills that plug into the STLC phases. Each folder holds a `SKILL.md`: a short header plus the instructions an AI assistant follows.

| Skill | What it does | From |
|---|---|---|
| [gatling-simulation-writer](gatling-simulation-writer/SKILL.md) | Writes Gatling load-test simulations in the Java DSL (also usable from Kotlin or Scala). | added here |
| [jmeter-test-plan-builder](jmeter-test-plan-builder/SKILL.md) | Builds Apache JMeter test plans for load testing web apps and APIs. | added here |
| [performance-ci-gate](performance-ci-gate/SKILL.md) | Adds automated performance regression checks to CI. | added here |
| [performance-results-analyzer](performance-results-analyzer/SKILL.md) | Analyses load-test results and finds the bottleneck. | added here |
| [performance-test-planner](performance-test-planner/SKILL.md) | Plan performance testing for an application or release. | added here |
| [web-performance-auditor](web-performance-auditor/SKILL.md) | Audits front-end web performance with Lighthouse and Core Web Vitals. | added here |

Search them by keyword with the [Test Skill Finder MCP](../../../README.md), or install one in Claude Code by copying
its folder to `~/.claude/skills/`.
