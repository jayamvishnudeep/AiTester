# Test Closure

Phase 7 of the software testing life cycle (STLC): 4 skills. Each folder holds a `SKILL.md`: a short header plus the instructions an AI assistant follows.

| Skill | What it does | From |
|---|---|---|
| [release-readiness-assessor](release-readiness-assessor/SKILL.md) | Assess whether a build is ready to release (go/no-go). | added here |
| [test-closure-reporter](test-closure-reporter/SKILL.md) | Produce the closure report that wraps up a test cycle. | skillmasterclass |
| [test-coverage-analyzer](test-coverage-analyzer/SKILL.md) | Find the gaps between what was required and what was actually tested. | skillmasterclass |
| [test-metrics-reporter](test-metrics-reporter/SKILL.md) | Calculate and explain test metrics from real execution and defect data. | added here |

Search them by keyword with the [Test Skill Finder MCP](../../README.md), or install one in Claude Code by copying
its folder to `~/.claude/skills/`.
