# Test Execution

Phase 5 of the software testing life cycle (STLC): 6 skills. Each folder holds a `SKILL.md`: a short header plus the instructions an AI assistant follows.

| Skill | What it does | From |
|---|---|---|
| [automation-script-generator](automation-script-generator/SKILL.md) | Turn an approved test case into a runnable automation script skeleton. | skillmasterclass |
| [chaos-experiment-designer](chaos-experiment-designer/SKILL.md) | Design controlled chaos engineering experiments to test resilience. | added here |
| [ci-test-pipeline-builder](ci-test-pipeline-builder/SKILL.md) | Design a CI pipeline that runs automated tests as quality gates. | added here |
| [etl-data-validator](etl-data-validator/SKILL.md) | Validate ETL and data pipelines: source-to-target completeness, correctness and quality. | added here |
| [regression-suite-selector](regression-suite-selector/SKILL.md) | Pick a targeted regression subset for a change instead of running the whole suite. | skillmasterclass |
| [test-execution-tracker](test-execution-tracker/SKILL.md) | Log and summarize the execution of a test cycle. | skillmasterclass |

Search them by keyword with the [Test Skill Finder MCP](../../README.md), or install one in Claude Code by copying
its folder to `~/.claude/skills/`.
