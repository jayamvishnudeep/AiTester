# Test Planning

Phase 2 of the software testing life cycle (STLC): 5 skills. Each folder holds a `SKILL.md`: a short header plus the instructions an AI assistant follows.

| Skill | What it does | From |
|---|---|---|
| [automation-framework-selector](automation-framework-selector/SKILL.md) | Recommend a test automation framework for a project. | added here |
| [risk-based-test-prioritizer](risk-based-test-prioritizer/SKILL.md) | Prioritise features, scenarios or test cases by risk. | added here |
| [test-estimation-calculator](test-estimation-calculator/SKILL.md) | Estimate testing effort for a release, feature or sprint. | added here |
| [test-plan-generator](test-plan-generator/SKILL.md) | Turn a JIRA ticket into a review-ready test plan. | skillmasterclass |
| [test-strategy-designer](test-strategy-designer/SKILL.md) | Design a test strategy for a product, release or team. | added here |

Search them by keyword with the [Test Skill Finder MCP](../../README.md), or install one in Claude Code by copying
its folder to `~/.claude/skills/`.
