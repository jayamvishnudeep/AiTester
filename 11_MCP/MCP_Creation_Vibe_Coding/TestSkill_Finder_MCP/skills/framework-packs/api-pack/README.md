# API testing pack

A framework pack: 6 skills that plug into the STLC phases. Each folder holds a `SKILL.md`: a short header plus the instructions an AI assistant follows.

| Skill | What it does | From |
|---|---|---|
| [api-contract-tester](api-contract-tester/SKILL.md) | Tests API contracts between consumers and providers with Pact or OpenAPI schema validation. | added here |
| [api-performance-tester](api-performance-tester/SKILL.md) | Plans and scripts API load tests with k6. | added here |
| [api-security-tester](api-security-tester/SKILL.md) | Plans authorized security tests for APIs based on the OWASP API Security Top 10 (2023). | added here |
| [graphql-api-tester](graphql-api-tester/SKILL.md) | Designs and writes tests for GraphQL APIs. | added here |
| [postman-collection-builder](postman-collection-builder/SKILL.md) | Builds Postman collections with test scripts and runs them with Newman in CI. | added here |
| [restassured-api-tester](restassured-api-tester/SKILL.md) | Generates Java API tests with REST Assured and TestNG or JUnit 5. | added here |

Search them by keyword with the [Test Skill Finder MCP](../../../README.md), or install one in Claude Code by copying
its folder to `~/.claude/skills/`.
