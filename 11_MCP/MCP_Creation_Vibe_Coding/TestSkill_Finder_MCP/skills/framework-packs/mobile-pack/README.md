# Mobile pack

A framework pack: 2 skills that plug into the STLC phases. Each folder holds a `SKILL.md`: a short header plus the instructions an AI assistant follows.

| Skill | What it does | From |
|---|---|---|
| [appium-test-generator](appium-test-generator/SKILL.md) | Generates mobile UI tests with Appium 2 for Android (UiAutomator2) and iOS (XCUITest). | added here |
| [mobile-test-matrix-planner](mobile-test-matrix-planner/SKILL.md) | Plans the device, OS and condition matrix for mobile app testing. | added here |

Search them by keyword with the [Test Skill Finder MCP](../../../README.md), or install one in Claude Code by copying
its folder to `~/.claude/skills/`.
