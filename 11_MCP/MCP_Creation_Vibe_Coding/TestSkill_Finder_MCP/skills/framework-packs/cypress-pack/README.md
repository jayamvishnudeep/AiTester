# Cypress pack

A framework pack: 6 skills that plug into the STLC phases. Each folder holds a `SKILL.md`: a short header plus the instructions an AI assistant follows.

| Skill | What it does | From |
|---|---|---|
| [cy-ci-configurator](cy-ci-configurator/SKILL.md) | Configures Cypress to run in CI (GitHub Actions, GitLab CI, Jenkins). | added here |
| [cy-component-tester](cy-component-tester/SKILL.md) | Writes Cypress component tests for React, Vue, Angular or Svelte components. | added here |
| [cy-custom-command-builder](cy-custom-command-builder/SKILL.md) | Builds reusable Cypress custom commands with TypeScript types. | added here |
| [cy-flaky-debugger](cy-flaky-debugger/SKILL.md) | Diagnoses and fixes flaky Cypress tests. | added here |
| [cy-intercept-mocker](cy-intercept-mocker/SKILL.md) | Stubs, spies on and waits for network calls in Cypress with cy.intercept. | added here |
| [cy-test-generator](cy-test-generator/SKILL.md) | Generates Cypress end-to-end tests in TypeScript from a user flow or a manual test case. | added here |

Search them by keyword with the [Test Skill Finder MCP](../../../README.md), or install one in Claude Code by copying
its folder to `~/.claude/skills/`.
