# AI Tester Master Class

This repository contains learning material and practical exercises from the AI Tester Master Class. The course focuses on applying AI engineering and prompt engineering techniques to software quality assurance.

## Course Topics

- Foundation models, language models, tokens, embeddings, and transformers
- Prompt engineering and few-shot prompting
- Anti-hallucination practices for reliable QA output
- RICE-POT prompt design
- Test-case generation and regression planning
- Bug-report creation, classification, analysis, and review
- API validation, authentication, contract, and error-handling testing
- Playwright, TypeScript, Selenium, Java, and enterprise automation concepts
- GitHub workflows, local LLMs, and AI-assisted testing tools
- Resume, LinkedIn, and QA career development

## Repository Structure

- `01_LLM_Basics/` contains foundational AI concepts and anti-hallucination rules.
- `02_Promt_Engineering/` contains prompt-engineering exercises, QA frameworks, VWO login testing, and test planning.
- `Notes.md` contains the structured, date-wise course notes and mentor templates.

## Study Approach

1. Learn the AI and transformer fundamentals.
2. Practice precise prompts with sufficient context.
3. Apply anti-hallucination checks.
4. Use RICE-POT to structure QA requests.
5. Validate generated test cases, bug reports, and automation code against evidence.
6. Keep credentials, API keys, and other secrets outside the repository.
