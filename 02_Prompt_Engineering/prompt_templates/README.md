# Prompt templates

Reusable prompts for everyday QA work, about a thousand lines in all. Copy one, fill in its placeholders, and
paste it with your own context.

| File | Lines | Prompts for |
|---|---|---|
| [test_case_prompts.md](test_case_prompts.md) | 190 | Generating test cases |
| [_bug_report_prompts.md](_bug_report_prompts.md) | 186 | Writing bug reports |
| [api_testing_prompts.md](api_testing_prompts.md) | 212 | Designing API tests |
| [API_Error_Handling_Tests.md](API_Error_Handling_Tests.md) | 23 | Error-path API tests |
| [code_review_prompts.md](code_review_prompts.md) | 213 | Reviewing code from a QA point of view |
| [context_templates.md](context_templates.md) | 210 | Building context as `.md` files, so a prompt starts from facts instead of a chat message |

`context_templates.md` is the idea the rest of the repository builds on: instructions and context belong in
files. See the [Prompt Engineering README](../README.md#the-template-library).
